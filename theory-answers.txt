M1C2 - Respuestas teoricas (UX/UI + Flexbox)

1) Nombra cuatro valores que se pueden usar con la propiedad justify-content.
- flex-start: alinea los elementos al inicio del eje principal.
- flex-end: alinea los elementos al final del eje principal.
- center: centra los elementos.
- space-between: distribuye el espacio dejando el primero al inicio y el ultimo al final.
Ejemplo: en una barra de navegacion, space-between ayuda a separar logo y links.

2) Que es un objetivo primordial?
Es el objetivo principal que un producto o pantalla debe lograr para el usuario. Es la accion mas importante que debe completar, y guia todas las decisiones de diseno.
Ejemplo: en una pagina de busqueda, el objetivo primordial es permitir encontrar informacion rapidamente. Buena practica: reducir ruido visual y hacer el buscador el elemento dominante.

3) Que son los wireframes de baja fidelidad?
Son bocetos simples que muestran la estructura y jerarquia de una interfaz sin detalles visuales finales (sin colores finales, tipografias exactas o imagenes reales).
Sirven para validar flujo y layout rapido. Buena practica: usar cajas y texto de placeholder para iterar antes de diseno visual.

4) Que es Git y para que sirve?
Git es un sistema de control de versiones distribuido. Sirve para guardar el historial de cambios, trabajar en equipo con ramas, y volver a versiones anteriores si algo falla.
Ejemplo: crear una rama para una nueva feature, hacer commits pequenos y luego hacer merge cuando esta lista.

5) Que es un mapa del sitio?
Es un diagrama o lista estructurada de las paginas de un sitio y sus relaciones. Ayuda a planificar navegacion y encontrar contenido.
Ejemplo: Home -> Productos -> Detalle de producto -> Checkout. Buena practica: mantenerlo simple y orientado a tareas del usuario.

6) Nombra tres valores que se pueden usar con flex-direction (incluye el valor por defecto).
- row (valor por defecto): elementos en fila de izquierda a derecha.
- column: elementos en columna de arriba hacia abajo.
- row-reverse o column-reverse: invierte el orden en fila o columna.
Ejemplo: usar column en un formulario para que los campos queden apilados.
